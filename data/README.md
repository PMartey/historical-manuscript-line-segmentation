# Data Directory

The full historical-document dataset is not stored in this repository.

To reproduce an experiment:

1. Obtain the source images through the original Newberry collection or the access method approved by the project authors.
2. Place locally obtained source images in `data/raw/`. This directory is ignored by Git.
3. Use only the small approved samples in `examples/input/` for the repository quick-start demonstration.
4. Read [DATA_POLICY.md](../DATA_POLICY.md ) before reusing, redistributing, or publishing derived data.
