# License Decision Before Public Release

Choose a license for the repository’s **original code** only after all project authors have agreed and any institutional requirements have been checked.

A public repository without a license is viewable and forkable on GitHub, but default copyright law generally does not grant broad permission to reuse, modify, or distribute the code. Common options to discuss are MIT, Apache-2.0, and GPL-3.0. See GitHub’s guide: <https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository>.

Do not assume the code license applies to archival scans, Newberry collection material, third-party dependencies, logos, or the supplied poster. Document those materials’ provenance and applicable terms separately.

After selecting a license, add the complete approved license text as `LICENSE` at the repository root, replace the license placeholder in `CITATION.cff`, and update the README License section.
