# Examples

Place only small, rights-cleared example materials in this directory.

| Directory | Contents |
|---|---|
| `input/` | One or more approved manuscript-page input images. |
| `output/` | The corresponding line-segmentation visualization and extracted line crops. |

For each example, document the source attribution, preprocessing settings, seam-carving parameters, exact command, and known quality limitations. Include at least one clearly segmented page and, if approved for sharing, one dense/overlapping cursive page that illustrates a documented failure mode.

Do not copy the full dataset into `examples/`. Read [`../DATA_POLICY.md`](../DATA_POLICY.md) before adding files.
